# 價格管理後台與 Microsoft 公司登入

## 入口

`https://pv-circonomy.vercel.app/admin/pricing/`。首頁漢堡選單的 Log in 直接啟動 Microsoft 登入，成功後進入價格設定；已有有效公司工作階段則直接進入，不重複登入。

## Microsoft Entra 設定

使用公司既有的單一租戶應用程式；租戶內使用者必須有 `pvcirconomy.com` 或 `tsgc.com.tw` 的公司登入名稱。外部 Microsoft 帳號、其他租戶與未來客戶帳號不具價格修改權。

Vercel Production 環境變數：

- `MICROSOFT_TENANT_ID`：Entra「概觀／基本資訊 → 租用戶識別碼」。
- `MICROSOFT_CLIENT_ID`：應用程式註冊 → 應用程式（用戶端）識別碼。
- `MICROSOFT_CLIENT_SECRET`：憑證及秘密 → 用戶端密碼的 **值**，不是秘密識別碼。不要貼在聊天。
- `AUTH_SECRET`：至少 32 字元的隨機簽署密鑰。可在可信任的本機用 `openssl rand -base64 48` 產生，再安全貼入 Vercel。
- `DATABASE_URL`：既有 Neon PostgreSQL 連線。
- `AUTH_ORIGIN`：選填，預設 `https://pv-circonomy.vercel.app`。自訂網域時需同步修改 Web Redirect URI。

Entra 平台選 **Web**，Redirect URI 設為：

`https://pv-circonomy.vercel.app/api/auth/microsoft/callback/`

使用 Authorization Code + PKCE，權限為 `openid profile email`；不需要讀取郵件或 Graph 資料。使用 ID token 驗證登入，不啟用 implicit grant。依租戶政策可能需要管理員同意或指派使用者。設定變數後須重新部署，變數才會套用到新部署。

登入檢查：Microsoft 簽章、issuer、audience、到期、nonce、tenant ID 及公司網域。公司網域檢查僅在成功驗證所設定租戶的 ID token 後執行。Session 為 HttpOnly / Secure / SameSite=Lax cookie，有效 8 小時。修改與登出另檢查 Origin；公開訪客即使直接呼叫 API 亦無修改權。

客戶登入未實作，本次不建立 Google 等 provider；未來客戶應使用獨立 customer 角色。不得因客戶登入或提交公司郵件字串直接授予 staff。

## 預設規則（使用者 2026-11-13 指定，取代舊範例）

- ≤300W：USD 10／片；USD 0.18／lb。
- 每增加 50W 或不足 50W：增加 USD 1.25／片；USD 0.025／lb。
- 301–350W：11.25／片；0.205／lb。
- 351–400W：12.50／片；0.230／lb。
- 401–450W：13.75／片；0.255／lb。
- Broken +10%、缺接線盒 +5%、缺框 +25%。可複選、百分比相加，全選 +40%。不連乘、不對運輸加價。
- 不再套用舊「缺框與破片擇高」或完整片 15% 討論。完整齊全無狀態加價。
- Drop off 費率仍待確認；沒有價格區間、不顯示為免費。
- Truck 按片。Trailer 以模型重量或面積估重得到預估總額，沒有重量時只顯示單價，不能沿用舊 45 lb 假設。最終仍按包含棧板、包材的過磅重量。

## 操作

後台可調整起始瓦數上限、級距寬度、按片與按重量的起始／增量價格，以及三種狀態百分比。右側即時試算與級距表使用尚未儲存的欄位；按「儲存並啟用價格」才改變啟用版本。

每次儲存留下不可由介面覆寫的版本、時間與公司帳號。可載入舊版內容再存成新版本。若另一位同事已更新，回傳 409 並保留本地輸入，避免覆蓋。歷史最多列出最近 30 版。

## 資料庫

僅新增 `pv_pricing_versions`、`pv_pricing_active`。初次讀取價格時在 transaction 與 advisory lock 下建立表格並植入初始版本；不修改既有型號或估價表。後續讀取不重設啟用版本。資料庫角色需具建立新表權限。

公開 `/api/pricing/` 僅回傳啟用規則／版本，不含管理員紀錄；`/api/admin/pricing/` 需 staff session。寫入採參數化 SQL 與啟用版本比對。資料庫無法讀取時回傳錯誤，前台不拿過期或默認價格冒充有效報價。

## 報價

前台讀取啟用版本。生成新文件前重新確認最新價格；已生成文件保留當時版本、規則、發行與 7 天到期時間。修改板片輸入後需重新生成。Condition 使用可複選的 Glass broken／Junction box missing／Frame missing 三個勾選框，依各項適用加價相加；全不選代表完整齊全。文件仍為使用者本地生成，不新增訂單、付款或配送預約。


## 統一登入入口

漢堡選單只有一個 Log in。完成 Microsoft 身分驗證後，必須同時符合設定的公司 tenant 與 pvcirconomy.com／tsgc.com.tw 網域，才取得 staff 權限並自動進入價格後台；已有有效 session 直接進入。不是以使用者自行輸入的 email 字串授權。其他網域目前不授予後台權限；未來新增 Google 等客戶登入時，應在同一入口提供 provider 並以獨立 customer 角色導向客戶頁面，不將客戶 session 當作 staff。

## 重量換算設定

新增五個可編輯欄位：雙玻 53.4 g/W、單玻＋背板 50.3 g/W、雙玻 12.25 kg/m²、單玻＋背板 10.76 kg/m²、未知 11.5 kg/m²。必須為正值；修改後儲存並啟用才生效。

首次升級會在既有初始化 transaction 與 advisory lock 中建立一個補齊係數的新版本，保留原價格與加價。舊版歷史可載入，缺少的係數以目前初始值補齊，再按儲存才會發行新版本。既有歷史列不覆寫。

Dimensions 直接依尺寸估重，不再搜尋候選型號；可依結構係數估算瓦數並套級距。Watts 加入 Panel construction，以功率估重及面積。面積不能當作唯一長寬規格。Quick-fill 已移除。

### 未知結構功率係數（2026-11-14）

價格管理新增 `unknownGramsPerWatt`（g/W），選填、必須大於 0，初始留空（資料庫 JSON null）。此欄位不會自動套用其他結構的平均值。設定並啟用後，Dimensions 的 Unknown 依 `面積 × unknownKgPerSqm × 1000 ÷ unknownGramsPerWatt` 推算瓦數，再套用既有瓦數級距；Watts 的 Unknown 也可用該係數估重，再以未知結構面積係數估算面積。所有換算均為推估。

舊的啟用版本會新增一個升級版本，只補空白係數、保留既有費率與舊版紀錄；管理員尚未設定係數時，Unknown 仍顯示待確認並說明原因。既有報價單保留其原版本與金額。

### 價格版本備註與前台同步（2026-11-14）

「價格設定備註 ＋」可展開輸入本次調整原因，最多 2,000 字元。備註與價格同次儲存、同一版本，版本紀錄會顯示；亦可不改費率、僅新增備註來建立新版本。舊版備註不覆寫，只有公司後台可讀取，不包含於公開價格或客戶報價快照。

前台在切回分頁、收到同來源後台儲存通知，以及頁面可見時每分鐘重新讀取啟用版本。更新不清除使用者輸入；版本變更後，畫面中尚未提交的報價草稿需重新產生。已保存報價單仍保留原版本與有效期。

### 備註標題與預填公式

備註展開區位於「回收價格規則」標題下方，取代原說明文字。收合時顯示可編輯的備註標題與「＋」；展開後可編輯標題及內文。舊版本沒有內文時，依該啟用版本的實際費率、係數自動預填計算邏輯；按「儲存並啟用價格」才寫入新版本。修改費率後，可按「填入目前欄位的計算邏輯」重建內文。自訂文字不會隨欄位變動自動覆寫。

### 換算＋價格比較預覽

右側可選瓦數、尺寸／面積或型號，顯示每片重量、等效瓦數／面積、瓦數級距、狀態加價、Truck／Trailer 單價、Trailer 約當每片價格與指定片數總費。瓦數及尺寸／面積輸入提供三種結構並列比較；型號採查得規格，保留已確認重量，不將假設結構覆蓋至型號。

預覽共用公開報價的重量、換算與計價函式，使用左側未儲存欄位，不寫入價格或訂單。面積換算只表示面積，不推定實際長寬；Trailer 僅為估重比較，結算仍按過磅重量。備註標題與內文區改為與下方整體工作區同寬。

價格欄位以三個 fieldset 分類：價格級距（6欄）、狀態加價（3欄）、重量與瓦數換算（6欄）；每區有對應說明。此分類不變更數值、版本儲存或計價公式。
