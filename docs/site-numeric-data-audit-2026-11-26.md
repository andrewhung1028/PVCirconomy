# PV Circonomy 數據來源稽核

2026 年 11 月 26 日，以公開正式站與對應部署來源為基準，另比對工作區差異。稽核覆蓋系統管理的 Excel 匯入與匯出定義、資料庫結構、公開 API 和 40 個正式頁面或市場路徑。六個市場的設備規格與詢價預填另以瀏覽器點驗。

## 已接到資料主檔

| 資料 | 現行路徑 | 待確認 |
| --- | --- | --- |
| 設備規格與電氣參數 | 系統管理的設備工作簿發布到設備版本，規格頁讀取發布值，必要時使用初始值。電氣功率按三相電壓、電流和功率因數計算。 | 公開值與初始值相符，正式設備工作簿版號需要管理權限確認。 |
| Our Solution | 市場工作簿管理情境、材料價值和營運參數。全球工作簿管理容量歷史、人口和共用常數。 | 查看已發布版本、有無舊版欄位補值，以及跨工作簿重複欄位的責任來源。 |
| Business Case | 工作簿管理地區、技術方案、OPEX、匯率、物料及回收假設。公開 API 回報 `Published master v2`，日本資料另由日本 Our Solution 參數轉換。 | `Payable` 可匯入及保存，目前未找到試算引擎使用此欄位。 |
| 回收價格與營運物流 | 各有資料庫版本，正式 API 均回傳版本。 | 系統管理尚無對應的 Excel 發布路徑。Our Solution 的運輸試算有獨立用途。 |

## 優先接線項目

| 項目 | 查核結果 | 建議歸屬 |
| --- | --- | --- |
| 設備行銷與比較 | 主頁卡片寫入 1 片／分鐘、1 位操作員、超過 99% 重量回收及最高 240,000 片／年。Basic 規格頁另顯示 115,200 片／年。 | 從設備主檔取得各配置額定值，另定義年產能宣稱的工時與稼動條件。 |
| 產能估算與詢價 | 線上估算仍由程式預填 260 日、1 班、8 小時、兩項每週維護各 4 小時，以及 85% 稼動率與速度。US 詢價預填每月 6,763 片。 | 用市場班表工作表管理估算預設，設備速率與人力從正式規格取得。 |
| MOU 設備概述 | 尺寸、適用模組及功率有獨立文字來源。Basic 規格頁顯示額定最大 62.2 kW，MOU 來源列安裝功率 85 kW。 | 核對兩個標示的定義，再接到設備主檔。空壓需求、測試基準及玻璃／含框厚度需欄位。 |
| 對外內容、圖面與案例 | 純度宣稱、材料示例、詢價預填、服務門檻和圖面標註散落在文案、模型預設及資產中。 | 設備指標依型號管理，市場政策依市場管理。案例與法規另保留來源、適用條件及生效資料。 |
| 價格、物流與外部行情 | 模組價格工作表是設備價格輸入，匯率有獨立行情來源，回收費率與配送由其他管理功能發布。 | 讓 Excel 接入現行版控。外部行情保留自動來源及報價時使用的日期與版本。 |

正式站工作簿下載需要管理員登入，稽核未取得私有工作簿或正式資料庫連線。欄位比對以部署程式的匯入、驗證及資料庫定義為基準，公開實值由正式 API 與瀏覽器抽查。代碼中出現的 UI 尺寸、單位換算、HTTP 狀態和資安限制應由各自的工程設定管理。已簽署或已出具的文件適用發行當時的快照。
