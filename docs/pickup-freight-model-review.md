# Pickup 運輸安排與運費建議

依 PV_Pickup_Freight_Calculator.numbers（表內研究日 2026-11-13）分析；以下公開費率僅引用表內數值，未逐一獨立核實來源，也不是承運人的正式報價。

## 工作簿模式

先以模組尺寸／重量、厚度、堆疊高度與單棧重量上限，推估每棧片數、棧數、包裝毛重、材積及線性英尺，再比較 LTL 與 FTL。LTL＝max(最低費, CWT×基準每CWT×貨類係數×距離係數×重量係數)×(1＋燃油比例)＋附加服務。FTL＝車次×max(每車最低費, 單程行車英里×全含每英里費率×加價係數)。

目前表內假設：48 in 含棧高度、35 mm 模組厚度、2500 lb 每棧上限、43,000 lb 車輛載重、99×630 in 拖車可用尺寸；均應以實際棧板／承運車型驗證。表內 LTL class 與重量係數皆為 1，整車最低費為 0，且沒有校正報價資料。

|案例|棧數|表內 LTL|表內 FTL|表內建議|
|---|---:|---:|---:|---|
|Phoenix 500片、322.5mi|18|7966.95|2005.95（2車）|FTL|
|Bakersfield 2000片、189.1mi|69|40559.68|3528.61（6車）|FTL|
|Las Vegas 120片、262.2mi、住宅＋吊門|5|2777.26|815.44（未含同等取貨服務）|LTL|

重點：整車最低費不能以零值作營運政策；比較兩種模式前須先確認都能執行同等服務。LTL 應有承運人適用上限，超過棧數、線性英尺或重量後改用 volume/partial/FTL，不把六台車的貨當普通單票LTL。載重應逐車分配，不只用平均棧重。吊門還須核對平台尺寸、額定載重與棧板相容性；「沒有月台」不等於「需要吊門」，若有合適堆高機可從地面裝車。公開牌價、產業平均與自訂占位混用需要實單校正。運費重量備援應共用網站的結構別係數，不另用固定0.053kg/W。

## 前台：客戶提供

1. 取貨完整美國地址、聯絡人、Email、電話；Google Maps 算行車距離。
2. 沿用估價單型號／尺寸、片數與Condition，避免重填。
3. 是否已完成棧板包裝；實際棧數、各類棧板外長寬高、包裝毛重（可標示不知道）、是否可堆疊。未包裝時由系統預估，需照片及後續確認。
4. 場址類型、是否有可用月台或足夠能力堆高機、是否需要尾門／搬運協助、車輛通行限制；不知道可選人工確認。
5. 期望取貨日期／上午下午；取貨現場照片與指示選填或於特殊條件時要求。
6. 顯示處理費、運輸費、附加服務、適用稅額及總額；未能定價或不符合承運條件時不顯示0元。送出為訂單申請，待公司確認。

## 後台：公司設定

- 目的地、收貨／Pickup各自容量、星期時段、禁用日期、備貨提前天數、航程與到貨時間安排。
- 車型、可用車廂長寬高、額定載重、尾門平台尺寸／載重、每車可裝棧數、可否堆疊與混裝。
- 包裝預設厚度、棧板皮重、包材、最大堆疊高度與每棧重量上限；將估算與客戶確認資料分開。
- 一般商業LTL、特殊服務尾門貨車、partial/專車、FTL 的適用條件；不把回收處理費的 Truck/Trailer 級距直接當承運服務分類。
- 各模式最低費、起始費、里程費（單程或往返明定）、燃油是否內含、服務區／航線調整、管理費或加價及報價有效期限。
- 住宅、有限通道、尾門、預約、等待、裝卸／包裝協助等附加服務及互斥／不重複計費規則；已含燃油的FTL不再套LTL燃油比例。
- 承運人實際報價、有效期、成本／對客售價、人工覆核、變更差額與客戶確認紀錄。

建議先以已合作承運人能執行的三類服務上線：一般商業棧板、需尾門／特殊協助、整車。符合自動計價條件者直接顯示費用；尺寸、重量、包裝或特殊服務待確認者建立待核價申請。至少用20–30筆有代表性的實際報價校正，再用保留樣本檢查誤差。網站現有 max(最低費,起始費＋單程行車英里×每英里費)×車數 可沿用專車模式，但不足以單獨代表LTL。
